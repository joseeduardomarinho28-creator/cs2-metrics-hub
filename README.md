# CS2 Analytics Hub

Advanced performance analysis and rating calculator for Counter-Strike 2.

## 🎯 Objective
To provide CS2 players with an objective analysis of their gameplay by calculating specific skill ratings (Aim, Utility, and Clutch) based on match history data.

## ✨ Planned Features
* Fetch player statistics and match history from competitive platforms.
* Calculate custom skill ratings (Aim, Utility, Clutch).
* Display player performance and progression over time.

## 🛠️ Tech Stack
* **Backend:** Python (FastAPI)
* **Frontend:** React (Planned)
* **Data Source:** Faceit API / Steam Web API
